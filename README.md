# Pendulo com movimento harmônico amortecido 
O respositório contém diversos gráficos úteis para a análise do movimento:
 - Gráfico Energia Cinética x Tempo;
 - Gráfico X x Tempo;
 - Gráfico Y x Tempo;
 - Gráfico de comparação da variação no eixo X e Y;
 - Gráfico de tendência em relação ao eixo X
Além de outros materiais decorrentes dos dois programas de python e dos Softwares SciDavis e Tracker.
Obs.: O arquivo em formato .trk deverá ser aberto usando o software Tracker.
